## ✨ Key Features

* 🪞 **True Glassmorphism UI:** A sleek, frosted-glass aesthetic applied flawlessly across the entire Discord interface.
* 🌅 **Dynamic 4K Wallpapers:** Scrapes wallpaper sources in real-time to serve you fresh, breathtaking high-resolution backgrounds. 
* 🔄 **Seamless Transitions:** Enjoy smooth, cinematic cross-fade animations whenever your background updates.
* 🎨 **Adaptive Color Engine:** Automatically analyzes the active wallpaper and adjusts the theme's accent colors to perfectly match the image's palette.

## 🚀 Installation

1. Download BetterDiscord if you haven't already.
2. Download the latest `GlassyWalls.plugin.js` from the [Releases](../../releases) page.
3. Open your BetterDiscord settings in Discord.
4. Go to **Plugins** -> **Open Plugin Folder** and drop the `.js` file in.
5. Enable it in your BetterDiscord settings.
*(Note: GlassyWalls handles all styling internally, so you don't need a separate `.css` theme file!)*

## ⚙️ Configuration

You can customize the plugin's behavior directly from the GlassyWalls menu, which can be opened using the button located in your Account Panel (bottom left):

*   **Custom URLs & Presets:** Add your own direct image or video URLs to use as backgrounds.
*   **Auto-Rotate:** How often the wallpaper automatically rotates.
*   **Blur & Texture Intensity:** Adjust the strength of the frosted glass effect and noise overlays.
*   **Performance Mode:** Toggles GPU Saver to remove real-time blurs if your PC is lagging.
*   **Manual Accent Color:** Override the dynamic color picker with your own chosen color.
