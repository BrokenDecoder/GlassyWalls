## ✨ Key Features

* 🪞 **True Glassmorphism UI:** A sleek, frosted-glass aesthetic applied flawlessly across the entire Discord interface.
* 🌅 **Dynamic 4K Wallpapers:** Scrapes *4kwallpapers.com* in real-time to serve you fresh, breathtaking high-resolution backgrounds. 
* 🔄 **Seamless Transitions:** Enjoy smooth, cinematic cross-fade animations whenever your background updates.
* 🎨 **Adaptive Color Engine:** Automatically analyzes the active wallpaper and adjusts the theme's accent colors to perfectly match the image's palette.

## 🚀 Installation

1. Download BetterDiscord if you haven't already.
2. Download the latest `.theme.css` and `[YourPluginName].plugin.js` from the [Releases](../../releases) page.
3. Open your BetterDiscord settings in Discord.
4. Go to **Plugins** -> **Open Plugin Folder** and drop the `.js` file in.
5. Go to **Themes** -> **Open Theme Folder** and drop the `.css` file in.
6. Enable both in your BetterDiscord settings.

## ⚙️ Configuration

You can customize the plugin's behavior directly from the BetterDiscord Plugins menu. Click the **Settings** gear icon next to **[Your Plugin Name]** to adjust:

*   **Update Interval:** How often the wallpaper changes (e.g., every 5 minutes, 1 hour, or daily).
*   **Wallpaper Categories:** Choose specific tags or categories from 4kwallpapers.com (e.g., Nature, Cyberpunk, Abstract).
*   **Blur Intensity:** Adjust the strength of the frosted glass effect.
*   **Color Saturation:** Tweak how vibrant the adaptive UI colors are.
